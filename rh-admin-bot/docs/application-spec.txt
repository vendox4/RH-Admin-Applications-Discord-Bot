RAS EL HANOUT — RH ADMIN APPLICATION BOT

Build a complete, production-ready Discord Admin Application Bot for the Discord server:

Ras El Hanout

Use:

* Node.js
* Discord.js v14
* SQLite
* Persistent database storage
* Slash commands
* Discord buttons
* Discord modals
* DM-based application system

The bot must survive restarts without losing applications, answers, timers, or review periods.

⸻

1. MOST IMPORTANT REQUIREMENT — LANGUAGE DISPLAY

The application is bilingual:

* Arabic
* English

IMPORTANT:

DO NOT MIX Arabic and English on the same line.

Every question must display as:

السؤال بالعربية
━━━━━━━━━━━━━━━━━━━━
English question

Arabic must always be in its own paragraph/block.

English must always be in its own paragraph/block.

Use RTL Unicode markers around Arabic text when necessary:

const RTL = "\u200F";

For example:

const arabicText = `${RTL}ما هو رابط حسابك على الستيم؟${RTL}`;

Do NOT create strings like:

ما هو رابط حسابك؟ — What is your Steam profile link?

because this can cause Arabic/English bidirectional rendering problems.

⸻

2. QUESTION EMBED FORMAT

Every question DM should use an embed.

Example:

RH ADMIN APPLICATION
Question 1 / 16
العربية
ما هو رابط حسابك على الستيم؟
━━━━━━━━━━━━━━━━━━━━
English
What is your Steam profile link?
Please reply with your answer.

The Arabic section must always be above the English section.

Use separate embed fields where appropriate.

Recommended structure:

embed.addFields(
    {
        name: "🇸🇦 العربية",
        value: `${RTL}${question.arabic}${RTL}`
    },
    {
        name: "🇬🇧 English",
        value: question.english
    }
);

This is extremely important.

5. QUESTION EMBED

Create:

src/embeds/question.js

IMPORTANT:

The Arabic and English MUST be separate embed fields.

const {
    EmbedBuilder
} = require("discord.js");
const gifs = require("../config/gifs");
const RTL = "\u200F";
function createQuestionEmbed(question, guild, totalQuestions = 16) {
    const embed = new EmbedBuilder()
        .setTitle("RH ADMIN APPLICATION")
        .setDescription(
            `**Question ${question.number} / ${totalQuestions}**`
        )
        .addFields(
            {
                name: "🇸🇦 العربية",
                value: `${RTL}${question.arabic}${RTL}`
            },
            {
                name: "━━━━━━━━━━━━━━━━━━━━",
                value: " "
            },
            {
                name: "🇬🇧 English",
                value: question.english
            }
        )
        .setFooter({
            text: "Ras El Hanout • RH Admin Applications"
        })
        .setTimestamp();
    if (guild) {
        const icon = guild.iconURL({
            extension: "png",
            size: 256
        });
        if (icon) {
            embed.setThumbnail(icon);
        }
    }
    if (gifs.QUESTION) {
        embed.setImage(gifs.QUESTION);
    }
    return embed;
}
module.exports = {
    createQuestionEmbed
};

6. IMPORTANT ARABIC RENDERING RULE

Do not use:

.setDescription(
    `${question.arabic} — ${question.english}`
)

Do not use:

value: `${question.arabic}\n${question.english}`

Instead always use:

.addFields(
    {
        name: "🇸🇦 العربية",
        value: `${RTL}${question.arabic}${RTL}`
    },
    {
        name: "━━━━━━━━━━━━━━━━━━━━",
        value: " "
    },
    {
        name: "🇬🇧 English",
        value: question.english
    }
)

This keeps the two languages visually separated.

12. RH ADMIN ROLE

RH Admin is manually managed.

The bot must NEVER automatically assign:

member.roles.add(RH_ADMIN_ROLE_ID)

after the 7-day period.

After 7 days:

Application status becomes:

READY_FOR_ADMIN_ROLE

Staff receives:

RH UNDER REVIEW COMPLETE
Applicant: @User
Application ID: RH-000123
The applicant has completed the 7-day Under Review period.
They are now eligible for manual RH Admin consideration.
The bot will NOT assign the RH Admin role automatically.
